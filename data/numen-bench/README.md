# Numen Bench 迁移数据

本目录保存从 `minecraft-numen` Bench 场景转换而来的 UTF-8 JSON 数据。来源场景基线是 Minecraft 1.21.1，当前项目目标版本是 26.2，因此矿物生成、配方和方块行为不能直接当作当前服务器事实。

这些文件用于：

- 评测 AgentLoop 的阶段规划和工具调用；
- 检查后端是否正确验证目标、工具、路径、掉落物和任务状态；
- 生成经过人工审核的少量示例轨迹。

`referencePlan` 是行为参考，不是必须复制的固定答案。生产执行时仍然必须读取当前服务器的观察、背包、配方和任务状态，并由后端校验每个动作。

六个场景分别覆盖隐藏矿脉、深层钻石、完整工具进阶链、自动合成、墙内箱子和方块建造。`chest_in_wall` 需要当前项目未来提供通用容器交互和物品交付工具；`iron_pickaxe_chain` 的熔炼步骤需要后端熔炼工具。
